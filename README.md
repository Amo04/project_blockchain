# Project Blockchain — Application Web3.0

Application blockchain pour l'envoi d'Ethereum 
et interaction avec des smart contracts.

## Stack technique
- Solidity 0.8.0
- Hardhat 3
- React + Vite
- ethers.js v5
- Tailwind CSS
- MetaMask
- Sepolia Testnet

## Smart Contract
Adresse : 0x8219931EC2370FB10D1E5450681C03AF08E37311
Réseau : Ethereum Sepolia

## Installation

### Smart Contract
cd smart_contract
npm install
npx hardhat compile

### Frontend
cd client
npm install
npm run dev

## Fonctionnalités
- Connexion wallet MetaMask
- Envoi d'ETH sur la blockchain
- Enregistrement des transactions dans le smart contract
- Historique des transactions
